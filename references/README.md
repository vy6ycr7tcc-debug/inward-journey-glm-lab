## The Three Things That Matter Most

1. **Materiality** — The user feels the difference between light and matter, between carved stone and textured boxes, between a real place and a 3D model. Every element must *feel* like what it is.

2. **Restraint** — The most powerful move is removing something. The final room is the philosophy: the Choice, alone, in light. Apply this everywhere.

3. **iPhone** — If it doesn't work beautifully on iPhone Safari, it doesn't work. Build mobile-safe from the start.
