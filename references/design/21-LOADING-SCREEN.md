# 21 — Loading Screen

## The User's Request

Remove the spoken narration that plays when the game loads. Replace it with **animated text**.

## What It Should Be

As the game loads, text appears — **letters rising from the bottom** of the screen. They **orbit around the loading icon**, then **float upward into infinity**.

The text carries a **short explanation of what the game is about** — just enough to orient the user, not a full introduction.

## The Voice

The text is **narrated in a new voice** — explicitly **not Aria** (the female voice used throughout the game). This is a different voice for a different moment — the threshold before the journey begins.

## Why This Matters

The loading screen is the first impression. The old version had a voice talking *at* the user before they'd even entered the world. The new version is more contemplative — text rising like breath, orbiting like planets, dissolving into infinity. It sets the tone: this is a place where things move slowly and beautifully.

The user is waiting. Instead of filling that wait with explanation, fill it with *feeling*.

## Nuance

- The letters shouldn't just scroll — they should **rise** (like bubbles, like breath)
- The **orbit** around the loading icon makes the icon feel like a gravitational center — a sun with words circling it
- **Floating up into infinity** — the text doesn't just disappear, it ascends. It goes somewhere.
- Keep the explanation **short**. A sentence or two. The game itself is the explanation.
